## 🎯 О проекте

**DevPath** — это интерактивное обучающее приложение, созданное для помощи начинающим программистам в освоении процесса разработки приложений.

### Проблема

Начинающие разработчики часто сталкиваются с:
- ❌ Непониманием полного цикла разработки
- ❌ Незнанием профессиональных терминов
- ❌ Отсутствием чёткого плана действий
- ❌ Сложностью выбора технологий и инструментов

### Решение

DevPath предоставляет:
- ✅ Пошаговое руководство из 10 этапов разработки
- ✅ Глоссарий из 35+ терминов с примерами
- ✅ Систему тестирования в стиле Duolingo (100 вопросов)
- ✅ Конфигуратор для подбора персонального пути
- ✅ Интерактивные подсказки при наведении на термины

## 🚀 Быстрый старт

### Требования

- Node.js 18+ 
- npm 9+

### Установка

```bash
# Клонировать репозиторий
git clone https://github.com/your-username/devpath.git
cd devpath

# Установить зависимости
npm install

# Запустить dev-сервер
npm run dev
```

Приложение будет доступно по адресу: `http://localhost:5173`

### Сборка для продакшена

```bash
# Создать production-сборку
npm run build

# Предпросмотр production-сборки
npm run preview
```

Результат будет в папке `dist/`

- Поддерживайте streak (ежедневную серию)

5. Используйте конфигуратор для планирования своего проекта

## 💻 Разработка

### Доступные скрипты

```bash
# Разработка
npm run dev          # Запуск dev-сервера с HMR

# Сборка
npm run build        # Production-сборка
npm run preview      # Предпросмотр production-сборки

# Линтинг
npm run lint         # Проверка кода ESLint
```

### Добавление нового контента

#### Добавить этап разработки

Откройте `src/data/stages.ts` и добавьте новый объект в массив `stages`:

```typescript
{
  id: "unique-id",
  number: 11,
  title: "Название этапа",
  required: true, // или false
  description: "Описание этапа",
  details: ["Пункт 1", "Пункт 2"],
  tips: ["Совет 1", "Совет 2"],
  tools: [
    { name: "Инструмент", url: "https://example.com" }
  ],
  commonMistakes: ["Ошибка 1", "Ошибка 2"]
}
```

#### Добавить термин в глоссарий

Откройте `src/data/glossary.ts` и добавьте:

```typescript
{
  id: "term-id",
  term: "Термин (Аббревиатура)",
  shortDefinition: "Краткое описание (1 строка)",
  definition: "Полное определение с деталями",
  example: "Практический пример использования",
  category: "Категория"
}
```

#### Добавить вопрос в тесты

Откройте `src/data/quiz.ts` и добавьте:

```typescript
{
  id: 101,
  question: "Вопрос?",
  options: ["Вариант 1", "Вариант 2", "Вариант 3", "Вариант 4"],
  correctAnswer: 1, // индекс правильного ответа (0-3)
  explanation: "Объяснение правильного ответа",
  difficulty: "easy", // "easy" | "medium" | "hard"
  unit: "basics" // ID юнита
}
```

### GitHub Pages

```bash

# Загрузить содержимое dist/ в ветку gh-pages
```

### Docker

```dockerfile

WORKDIR /app
COPY package*.json ./
RUN npm ci
COPY . .
RUN npm run build

FROM nginx:alpine
COPY --from=build /app/dist /usr/share/nginx/html
EXPOSE 80
CMD ["nginx", "-g", "daemon off;"]
```
